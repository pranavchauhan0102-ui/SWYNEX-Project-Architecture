# InternTrack – Internship Application Tracker

A proposed full-stack web application architecture developed as part of the SWYNEX Technologies internship program.

## Overview

InternTrack aims to help students and job seekers organize their internship applications, monitor application statuses, and manage important deadlines through a centralized dashboard.

## Key Features

- Add, edit, view, and delete internship applications.
- Track application progress.
- Search and filter applications.
- Monitor important deadlines.
- View application statistics.

## Proposed Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- API: REST API
- Database: MongoDB
- Version Control: Git and GitHub
